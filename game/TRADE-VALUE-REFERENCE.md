# Trade value and market reference

## How the simulation estimates value

The trade model uses shared relative units, not dollars or a promise of what a player will return. Player estimates combine current simulation rating, age, upside, contract control, cap hit, recent production, club plan and roster need. Ratings are estimates; the market formula is a gameplay aid, not a claim that a club would make a specific offer. Draft picks use one declining scale across rounds and years. Club need and role designations add bounded bonuses instead of multiplying a player's value several times.

Each proposed package shows separate grades for both clubs using that club's modeled value received compared with value sent. A warning appears when a club gives up over 20% more modeled value than it receives. The warning is a negotiation aid; teams can still value fit, leverage, retention and timing differently.

## What the 2025–26 trade market adds

- **Jordan Kyrou to Washington (completed, June 2026):** St. Louis received Connor McMichael, a first-round pick and prospect Milton Gastrin: one established forward for a three-piece return. [NHL.com](https://www.nhl.com/news/jordan-kyrou-traded-to-washington-capitals-by-st-louis-blues)
- **Rasmus Andersson to Vegas (completed, January 2026):** Calgary received Zach Whitecloud, a defense prospect, and conditional first- and second-round picks. This is a good model for a high-impact defenseman moving in a package. [NHL.com](https://www.nhl.com/news/rasmus-andersson-traded-to-golden-knights-by-flames)
- **Mackenzie Weegar to Utah (completed, March 2026):** Calgary received Olli Maatta, prospect Jonathan Castagna and three second-round picks. [NHL.com](https://www.nhl.com/news/mackenzie-weegar-traded-to-utah-mammoth-by-calgary-flames)
- **One-for-one exception — Kaedan Korczak for Parker Wotherspoon (completed, June 2026):** Vegas and Pittsburgh swapped defensemen directly. Comparable role and roster fit can make a clean swap sensible, but that structure should not be the default for a major target. [NHL.com trade tracker](https://www.nhl.com/news/topic/trade-coverage/2025-26-nhl-trades)
- **JJ Peterka to Boston (completed, June 2026):** Utah received two first-round picks. A young scorer with team control can command a pick-heavy return without a roster player. [NHL.com](https://www.nhl.com/news/topic/trade-coverage/jj-peterka-traded-to-boston-bruins-by-utah-mammoth-for-two-first-round-picks)

The model should favor a package when the target is an impact player: typically a combination of a roster player or prospect and one or more picks. A direct roster-player swap is allowed only as an exception when modeled values are within 8% and the seller has a positional need for the incoming player. Package returns receive a preference when they are reasonably close to the ask. AI deadline packages can include picks, a reserve player, an organizational prospect or an NHL roster player; both clubs’ cap projections and player destination protections are checked. Roster size itself does not block the trade. Packages can also be pick-heavy or player-heavy; the model should not require every package to contain all asset types.

## Rumor and completed deals

- **Owen Tippett / Philadelphia asking framework (rumor):** Daily Faceoff reported that a package to make Philadelphia consider moving Tippett could look like a first-round pick, a decent prospect and a mid-tier roster player. This is a reported asking framework, not a completed trade and not evidence Boston made that offer. [Daily Faceoff report](https://www.dailyfaceoff.com/news/philadelphia-flyers-asking-price-trade-deadline-rasmus-ristolainen-owen-tippett-bruins-red-wings-stars)
- **Sean Monahan to Winnipeg (completed, 2024):** Winnipeg paid a 2024 first-round pick and a conditional 2027 third-round pick for a center headed to a playoff push. [NHL.com](https://www.nhl.com/news/sean-monahan-prepared-to-play-key-role-in-winnipeg-jets-playoff-push)
- **Jake Guentzel to Carolina (completed, 2024):** Carolina sent Michael Bunting, three prospects, a conditional first-round pick and a conditional fifth-round pick for a high-end rental. This illustrates how a buyer may combine a roster player, prospects and picks. [NHL.com](https://www.nhl.com/news/carolina-hurricanes-face-offseason-with-9-potential-unrestricted-free-agents)
- **Mikko Rantanen three-team trade (completed, 2025):** Carolina received Martin Necas, Jack Drury and second- and fourth-round picks for Rantanen and Taylor Hall; the deal also involved Chicago and salary retention. This was a star-level, multi-club situation, not a direct comparable for Tippett. [NHL.com](https://www.nhl.com/news/mikko-rantanen-taylor-hall-traded-to-hurricanes-in-three-team-deal)

These examples show why a single player-to-player rating cannot reliably dictate a return. Contract status, buyer competition, retention, player consent and the seller's goals can change the package substantially. A rumor is not a completed trade and should not be used as a transaction precedent.
